# ztk Phase 1 (Core) Implementation Plan

**Goal:** A native `ztk2` binary that replaces the task-lifecycle half of the bash `ztk`: config, Taskwarrior integration, task commands, task notes, the argument guard, JSON/human output, and bash completion with Taskwarrior fallback.

**Architecture:** One Maven module. Æsh parses commands in non-interactive mode (`AeshRuntimeRunner`). Every Taskwarrior call goes through `TaskStore`, which runs the `task` binary with an argument list and parses `export` JSON. Commands produce results through `Output`, which picks human or JSON rendering. Errors are `ZtkException`s carrying the spec's exit codes.

**Tech Stack:** Java 25, Æsh 3.18.2, Jackson databind 2.22.3 (tree model only, no reflection binding), JUnit Jupiter 6.1.3, AssertJ 3.27.7, GraalVM 25 `native-image` via `native-maven-plugin` 0.11.1, Taskwarrior ≥ 3.0 (installed: 3.5.0).

**Spec:** `docs/specs/2026-10-15-ztk-design.md` (§3 config, §6.1 output contract, §6.2 Tasks/Notes rows, §7 architecture, §7.1, §7.2, §8, §11).

**Deferred within the spec:** `help [command]` as a subcommand. Phase 1 has `--help` on every command and the root; add `help` in Phase 5 if still wanted.

**Out of scope for Phase 1** (later plans): vault/graph/search (Phase 2), goals/efforts and the `--effort` option (Phase 3), sessions and reports (Phase 4), migration, skills, and `install-skills` (Phase 5). The `note` UDA is introduced now because `start`/`begin`/`touch` need it.

**Plan status:** this plan is a draft. Versions and code snippets are suggestions; the actual implementation is decided per task (e.g. the pom uses Æsh 3.18.x with `aesh-processor`, Jackson 3 `tools.jackson`, AssertJ 4, native plugin 1.1.x).

**Done (Tasks 1–10), all green:** project bootstrap; Æsh spike; `ZtkException`; `configuration.ConfigurationLoader`; `TestTaskwarrior` fixture; `taskwarrior.TaskStore` (reads, writes, version check, `note` UDA via `rc.` overrides); `tasks.Tasks.add` creating the task and its note; CLI (`Ztk.run`, `Context`, `cli.ZtkInvocation`, `config show`, `add`, `ArgumentGuard`, global `--json`/`--human`/`--config`, single error handler); no ANSI colors in help/usage outside an interactive session or with `NO_COLOR` (`Context.colors()`).

**How the code differs from the draft below** (the draft is reference only):
- Names: `configuration.Configuration`/`ConfigurationLoader`, env passed as `Properties`; no `include` in the config format.
- Commands implement `Command<ZtkInvocation>`; `ZtkInvocation` wraps Æsh's invocation, carries `Context`, and fixes `printErr` (Æsh sends it to stdout). No static/`ScopedValue` context.
- Output: one rule for all commands (JSON when stdin or stdout is piped, or with `--json`; human in an interactive session or with `--human`); commands call `invocation.result(human, json)` themselves. No path-result exception (spec §6.1 updated). The interactive check stays `System.console() != null` (stdin and stdout are terminals); a stdout-only check was considered and rejected as more code for one case (`… | ztk … --summary -`) that `--human` covers.
- Help colors: Æsh only honors the real `NO_COLOR` and never checks for a terminal. `Ztk.run` uses `lazyStartup(false)` plus a `ContainerBuilder` calling `updateAnsiMode`, and also updates positional arguments, which Æsh's `updateAnsiMode` (and its own `NO_COLOR` handling) skips. Both are worth reporting upstream.
- Global options are declared on `ZtkCommand` (inherited, for acceptance and help) but read by `Ztk.GlobalOptions.parse`, because Æsh does not pass inherited values through nested groups.
- `add` creates the note (`touch` removed from the spec); `TaskNotes` is package-private behind `Tasks`.
- `begin` is folded into `start`: it prints the note path, and `--editor`/`-e` opens it. No `begin` alias. `TaskNotes.create` returns the linked or legacy (`task_uuid` frontmatter) note before creating one; there is no separate `ensure`.

## Spike results (Task 2, 2026-10-15) — decision: keep Æsh

Æsh 3.18.3, JVM and GraalVM 25 native behave identically.

| Check | Result |
|---|---|
| a `add --help` | Usage, exit 0 |
| b `add fix bug project:X +week` | Words passed through, exit 0 |
| c `add fix --force` | "The option --force is unknown." + command usage, **exit 2** |
| d `add fix -week` | **Accepted** as a positional (`add [fix, -week]`), exit 0 |
| e `start 3 --summary -` | `summary=-` |
| f `bogus` | "'ztk bogus' is not a subcommand…" + root usage, **exit 2** (not 127) |
| g `--aesh-complete -- st` | `start<TAB>Start a task` then `__aesh_file__` |
| h `--aesh-complete -- add fix` | `__aesh_file__` only |
| i `--aesh-completion bash` | Dynamic script calling `ztk --aesh-complete -- "${COMP_WORDS[@]:1}"`; handles `__aesh_file__`/`__aesh_dir__` sentinels; no extension hook |
| Timing (native) | 20 completion calls in 0.061 s (~3 ms/call; budget 50 ms) |

Consequences for later tasks:

- **Annotation processing:** JDK 23+ javac ignores processors on the classpath. `aesh-processor` is declared in `maven-compiler-plugin` `annotationProcessorPaths`; it generates `*_AeshMetadata` classes and `META-INF/native-image/org.aesh/*/reflect-config.json`, so no tracing agent is needed. Annotated fields must be package-private (not private) to avoid reflection.
- **Native build** needs `--enable-native-access=ALL-UNNAMED` (aesh-readline uses FFM on GraalVM 25).
- **Exit codes:** Æsh returns `USAGE_ERROR` (2) for unknown options and unknown subcommands. `Ztk.run` maps it to the spec's 1.
- **Argument guard is ours:** Æsh rejects unknown `--long` options but passes single-dash tokens (`-week`) through as positionals. The guard rejects any positional starting with `-` except a lone `-`, before the command does anything.
- **Completion:** candidates are `name<TAB>description`; `__aesh_file__` is the file-fallback sentinel from `completeFallback = DEFAULT`. Set `completeFallback = NONE` on the root so an empty answer means "Æsh has nothing", which is where `completion.bash` hands over to Taskwarrior. The generated script hard-codes the program name (`.completionProgramName("ztk2")` during the transition) and has no fallback hook, so Task 13 writes its own small wrapper modelled on it.

## Conventions for every task

- Base package: `io.github.jabolina.ztk`. Paths below are relative to `/home/jab/rambling/ztk`.
- Run tests with `mvn -q test` (all) or `mvn -q test -Dtest=ClassName` (one class).

- Commands never call `System.exit` and never print directly; they return results through `Output` or throw `ZtkException`.
- No `var` (the user's Java style).

```java
package io.github.jabolina.ztk.spike;

import java.util.List;

import org.aesh.AeshRuntimeRunner;
import org.aesh.command.Command;
import org.aesh.command.CommandDefinition;
import org.aesh.command.CommandResult;
import org.aesh.command.invocation.CommandInvocation;
import org.aesh.command.option.Arguments;
import org.aesh.command.option.Option;

public final class SpikeMain {

    @CommandDefinition(name = "ztk", description = "spike", generateHelp = true,
            groupCommands = {Add.class, Start.class})
    public static class Root implements Command<CommandInvocation> {
        @Override
        public CommandResult execute(CommandInvocation invocation) {
            System.out.println("root");
            return CommandResult.SUCCESS;
        }
    }

    @CommandDefinition(name = "add", description = "Add a task", generateHelp = true)
    public static class Add implements Command<CommandInvocation> {
        @Arguments
        private List<String> words;

        @Override
        public CommandResult execute(CommandInvocation invocation) {
            System.out.println("add " + words);
            return CommandResult.SUCCESS;
        }
    }

    @CommandDefinition(name = "start", description = "Start a task", generateHelp = true)
    public static class Start implements Command<CommandInvocation> {
        @Arguments
        private List<String> ids;

        @Option(name = "summary", hasValue = true)
        private String summary;

        @Override
        public CommandResult execute(CommandInvocation invocation) {
            System.out.println("start " + ids + " summary=" + summary);
            return CommandResult.SUCCESS;
        }
    }

    public static void main(String[] args) {
        CommandResult result = AeshRuntimeRunner.builder().command(Root.class).args(args).execute();
        System.exit(result.getResultValue());
    }
}
```

```java
package io.github.jabolina.ztk;

/**
 * Failure carrying the process exit code defined in the spec (§6.1).
 */
public final class ZtkException extends RuntimeException {
    public static final int USAGE = 1;
    public static final int NOT_FOUND = 2;
    public static final int VALIDATION = 3;
    public static final int TASKWARRIOR = 4;

    private final int exitCode;

    public ZtkException(int exitCode, String message) {
        super(message);
        this.exitCode = exitCode;
    }

    public int exitCode() {
        return exitCode;
    }

    public static ZtkException usage(String message) {
        return new ZtkException(USAGE, message);
    }

    public static ZtkException notFound(String message) {
        return new ZtkException(NOT_FOUND, message);
    }

    public static ZtkException validation(String message) {
        return new ZtkException(VALIDATION, message);
    }

    public static ZtkException taskwarrior(String message) {
        return new ZtkException(TASKWARRIOR, message);
    }
}
```

```java
package io.github.jabolina.ztk.config;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Map;
import java.util.Optional;

import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.io.TempDir;

import io.github.jabolina.ztk.ZtkException;

class ConfigLoaderTest {

    @TempDir
    Path home;

    private Path data() throws IOException {
        return Files.createDirectories(home.resolve("cerebro"));
    }

    private Path write(Path file, String content) throws IOException {
        Files.createDirectories(file.getParent());
        return Files.writeString(file, content);
    }

    @Test
    void explicitFlagWins() throws IOException {
        Path data = data();
        Path flag = write(home.resolve("flag.rc"), "data.location=" + data + "\n");
        write(home.resolve(".ztkrc"), "data.location=/nonexistent\n");

        Config config = ConfigLoader.load(Optional.of(flag), Map.of("HOME", home.toString()));

        assertThat(config.dataLocation()).isEqualTo(data);
        assertThat(config.source()).isEqualTo(flag);
    }

    @Test
    void lookupOrderEnvThenXdgThenHome() throws IOException {
        Path data = data();
        Path env = write(home.resolve("env.rc"), "data.location=" + data + "\n");
        Path xdg = write(home.resolve(".config/ztk/ztkrc"), "data.location=" + data + "\n");
        Path dot = write(home.resolve(".ztkrc"), "data.location=" + data + "\n");

        assertThat(ConfigLoader.load(Optional.empty(),
                Map.of("HOME", home.toString(), "ZTKRC", env.toString())).source()).isEqualTo(env);
        assertThat(ConfigLoader.load(Optional.empty(), Map.of("HOME", home.toString())).source()).isEqualTo(xdg);
        Files.delete(xdg);
        assertThat(ConfigLoader.load(Optional.empty(), Map.of("HOME", home.toString())).source()).isEqualTo(dot);
    }

    @Test
    void xdgConfigHomeIsHonored() throws IOException {
        Path data = data();
        Path custom = write(home.resolve("xdg/ztk/ztkrc"), "data.location=" + data + "\n");

        Config config = ConfigLoader.load(Optional.empty(),
                Map.of("HOME", home.toString(), "XDG_CONFIG_HOME", home.resolve("xdg").toString()));

        assertThat(config.source()).isEqualTo(custom);
    }

    @Test
    void parsesCommentsBlankLinesTildeAndDefaults() throws IOException {
        data();
        Path rc = write(home.resolve(".ztkrc"), """
                # a comment

                data.location=~/cerebro
                task.rc=~/test.taskrc
                """);

        Config config = ConfigLoader.load(Optional.of(rc), Map.of("HOME", home.toString(), "EDITOR", "vim"));

        assertThat(config.dataLocation()).isEqualTo(home.resolve("cerebro"));
        assertThat(config.taskRc()).contains(home.resolve("test.taskrc"));
        assertThat(config.taskData()).isEmpty();
        assertThat(config.taskCommand()).isEqualTo("task");
        assertThat(config.editor()).isEqualTo("vim");
    }

    void editorFallsBackToNvim() throws IOException {
        Path rc = write(home.resolve(".ztkrc"), "data.location=" + data() + "\n");

        assertThat(ConfigLoader.load(Optional.of(rc), Map.of("HOME", home.toString())).editor()).isEqualTo("nvim");
    }

    @Test
    void includeIsResolvedRelativeToIncludingFile() throws IOException {
        Path data = data();
        write(home.resolve("conf/extra.rc"), "data.location=" + data + "\ntask.command=/usr/bin/task\n");
```

```java
package io.github.jabolina.ztk.config;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.HashSet;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.Set;

import io.github.jabolina.ztk.ZtkException;

public final class ConfigLoader {

    static final String SAMPLE = """
            # ~/.config/ztk/ztkrc
            data.location=~/cerebro
            """;

    private ConfigLoader() {
    }

    public static Config load(Optional<Path> explicit, Map<String, String> env) {
        String home = env.getOrDefault("HOME", System.getProperty("user.home"));
        List<Path> candidates = candidates(explicit, env, home);
        Path source = null;
        for (Path candidate : candidates) {
            if (Files.isRegularFile(candidate)) {
                source = candidate;
                break;
            }
        }
        if (source == null) {
            StringBuilder message = new StringBuilder("No ztk configuration found. Looked in:\n");
            for (Path candidate : candidates) {
                message.append("  ").append(candidate).append('\n');
            }
            message.append("Create one, for example:\n").append(SAMPLE);
            throw ZtkException.usage(message.toString());
        }

        Map<String, String> values = new LinkedHashMap<>();
        parse(source, values, new HashSet<>(), home);

        String location = values.get("data.location");
        if (location == null) {
            throw ZtkException.usage("Missing required key data.location in " + source + "\n" + SAMPLE);
        }
        Path dataLocation = Path.of(location);
        if (!Files.isDirectory(dataLocation)) {
            throw ZtkException.usage("data.location is not a directory: " + dataLocation + " (from " + source + ")");
        }
        String editor = values.getOrDefault("editor", env.getOrDefault("EDITOR", "nvim"));
        return new Config(source, Map.copyOf(values), dataLocation, editor);
    }

    private static List<Path> candidates(Optional<Path> explicit, Map<String, String> env, String home) {
        if (explicit.isPresent()) {
            return List.of(explicit.get());
        }
        List<Path> paths = new ArrayList<>();
        if (env.containsKey("ZTKRC")) {
            paths.add(Path.of(expand(env.get("ZTKRC"), home)));
        }
        String xdg = env.getOrDefault("XDG_CONFIG_HOME", home + "/.config");
        paths.add(Path.of(xdg, "ztk", "ztkrc"));
        paths.add(Path.of(home, ".ztkrc"));
        return paths;
    }

    private static void parse(Path file, Map<String, String> values, Set<Path> visiting, String home) {
        Path normalized = file.toAbsolutePath().normalize();
        if (!visiting.add(normalized)) {
            throw ZtkException.usage("Config include cycle at " + normalized);
        }
        List<String> lines;
        try {
            lines = Files.readAllLines(normalized);
        } catch (IOException e) {
            throw ZtkException.usage("Cannot read config " + normalized + ": " + e.getMessage());
        }
        for (int i = 0; i < lines.size(); i++) {
            String line = lines.get(i).strip();
            if (line.isEmpty() || line.startsWith("#")) {
                continue;
            }
            if (line.startsWith("include ")) {
                Path included = Path.of(expand(line.substring("include ".length()).strip(), home));
                parse(normalized.getParent().resolve(included), values, visiting, home);
                continue;
            }
            int eq = line.indexOf('=');
            if (eq <= 0) {
                throw ZtkException.usage("Malformed config line " + normalized + ":" + (i + 1) + ": " + line);
            }
            String key = line.substring(0, eq).strip();
            String value = expand(line.substring(eq + 1).strip(), home);
            values.put(key, value);
        }
        visiting.remove(normalized);
    }

    private static String expand(String value, String home) {
        if (value.equals("~")) {
            return home;
        }
        if (value.startsWith("~/")) {
            return home + value.substring(1);
        }
        return value;
    }
}
```

```java
package io.github.jabolina.ztk.taskwarrior;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;
import java.util.regex.Pattern;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;

import io.github.jabolina.ztk.ZtkException;
import io.github.jabolina.ztk.config.Config;

/**
 * The only code that runs the Taskwarrior binary (spec §7.1).
 */
public final class TaskStore {
    private static final Pattern REF = Pattern.compile("\\d+|[0-9a-f]{8}(-[0-9a-f]{4}){3}-[0-9a-f]{12}");
    private static final ObjectMapper JSON = new ObjectMapper();

    private final Config config;

    private TaskStore(Config config) {
        this.config = config;
    }

    public static TaskStore create(Config config) {
        return new TaskStore(config);
    }

    public List<Task> query(String... filter) {
        List<String> args = new ArrayList<>(List.of("rc.json.array=on"));
        args.addAll(List.of(filter));
        args.add("export");
        JsonNode array = parse(run(args));
        List<Task> tasks = new ArrayList<>();
        array.forEach(node -> tasks.add(new Task(node)));
        return tasks;
    }

    /** Resolves a task by numeric id or uuid; exit 2 if absent. */
    public Task get(String ref) {
        if (!REF.matcher(ref).matches()) {
            throw ZtkException.usage("Not a task id or uuid: " + ref);
        }
        List<Task> tasks = query(ref);
        if (tasks.isEmpty()) {
            throw ZtkException.notFound("Task " + ref + " not found.");
        }
        return tasks.getFirst();
    }

    String run(List<String> args) {
        List<String> command = new ArrayList<>();
        command.add(config.taskCommand());
        command.add("rc.verbose=nothing");
        command.add("rc.confirmation=off");
        command.addAll(args);
        ProcessBuilder builder = new ProcessBuilder(command);
        config.taskRc().ifPresent(rc -> builder.environment().put("TASKRC", rc.toString()));
        config.taskData().ifPresent(data -> builder.environment().put("TASKDATA", data.toString()));
        try {
            Process process = builder.start();
            String out = new String(process.getInputStream().readAllBytes(), StandardCharsets.UTF_8);
            String err = new String(process.getErrorStream().readAllBytes(), StandardCharsets.UTF_8);
            if (process.waitFor() != 0) {
                throw ZtkException.taskwarrior("Taskwarrior failed: " + String.join(" ", args) + "\n" + err.strip());
            }
            return out;
        } catch (IOException e) {
            throw ZtkException.taskwarrior("Cannot run " + config.taskCommand() + ": " + e.getMessage());
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw ZtkException.taskwarrior("Interrupted while running Taskwarrior");
        }
    }

    private static JsonNode parse(String json) {
        try {
            return JSON.readTree(json.isBlank() ? "[]" : json);
        } catch (IOException e) {
            throw ZtkException.taskwarrior("Unparseable Taskwarrior output: " + e.getMessage());
        }
    }
}
```

```java
package io.github.jabolina.ztk.notes;

import java.io.IOException;
import java.io.UncheckedIOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;
import java.time.LocalDate;
import java.time.ZonedDateTime;
import java.time.format.DateTimeFormatter;
import java.util.List;
import java.util.Optional;
import java.util.function.Supplier;
import java.util.stream.Stream;

import io.github.jabolina.ztk.ZtkException;
import io.github.jabolina.ztk.config.Config;
import io.github.jabolina.ztk.taskwarrior.Task;
import io.github.jabolina.ztk.taskwarrior.TaskStore;

/**
 * Locates or creates the note attached to a task and keeps the `note` UDA in sync.
 */
public final class TaskNotes {
    private static final DateTimeFormatter PREFIX = DateTimeFormatter.BASIC_ISO_DATE;

    private final Config config;
    private final TaskStore store;
    private final Supplier<LocalDate> today;

    public TaskNotes(Config config, TaskStore store, Supplier<LocalDate> today) {
        this.config = config;
        this.store = store;
        this.today = today;
    }

    /** Existing note for the task, if any (backfills the UDA when found by frontmatter). */
    public Optional<Path> find(Task task) {
        Optional<Path> fromUda = task.uda("note")
                .map(relative -> config.dataLocation().resolve(relative))
                .filter(Files::isRegularFile);
        if (fromUda.isPresent()) {
            return fromUda;
        }
        Optional<Path> legacy = findByFrontmatter(task.uuid());
        legacy.ifPresent(path -> link(task, path));
        return legacy;
    }

    /** Existing or newly created note for the task. */
    public Path ensure(Task task) {
        Optional<Path> existing = find(task);
        if (existing.isPresent()) {
            return existing.get();
        }
        String project = task.project().orElseThrow(() -> ZtkException.validation(
                "Task " + task.id() + " has no project. Assign one with: task " + task.id() + " modify project:<name>"));
        Path note = config.dataLocation().resolve(project)
                .resolve(today.get().format(PREFIX) + "-" + slug(task.description()) + ".md");
        write(note, template(task, project));
        link(task, note);
        return note;
    }

    static String slug(String text) {
        String slug = text.toLowerCase().replaceAll("[^a-z0-9]+", "-").replaceAll("^-|-$", "");
        return slug.length() > 80 ? slug.substring(0, 80).replaceAll("-$", "") : slug;
    }

    private void link(Task task, Path note) {
        String relative = config.dataLocation().relativize(note).toString();
        if (!task.uda("note").map(relative::equals).orElse(false)) {
            store.modify(task, List.of("note:" + relative));
        }
    }

    private Optional<Path> findByFrontmatter(String uuid) {
        String needle = "task_uuid: " + uuid;
        try (Stream<Path> files = Files.walk(config.dataLocation())) {
            return files.filter(path -> path.toString().endsWith(".md"))
                    .filter(Files::isRegularFile)
                    .filter(path -> contains(path, needle))
                    .findFirst();
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        }
    }

    private static boolean contains(Path path, String needle) {
        try (Stream<String> lines = Files.lines(path)) {
            return lines.limit(20).anyMatch(line -> line.strip().equals(needle));
        } catch (IOException | UncheckedIOException e) {
            return false;
        }
    }

    private String template(Task task, String project) {
        String issue = task.uda("issue").orElse("");
        StringBuilder body = new StringBuilder()
                .append("---\n")
                .append("title: ").append(task.description()).append('\n')
                .append("date: ").append(ZonedDateTime.now().format(DateTimeFormatter.RFC_1123_DATE_TIME)).append('\n')
                .append("task_uuid: ").append(task.uuid()).append('\n')
                .append("project: ").append(project).append('\n')
                .append("issue: ").append(issue).append('\n')
                .append("---\n\n");
        if (!issue.isEmpty()) {
            body.append("Ref: **").append(issue).append("**\n\n");
        }
        return body.append("# Notes\n\n").toString();
    }

    /** Atomic write: temp file in the same directory, then rename (spec §8). */
    static void write(Path target, String content) {
        try {
            Files.createDirectories(target.getParent());
            Path temp = Files.createTempFile(target.getParent(), ".ztk-", ".tmp");
            Files.writeString(temp, content);
            Files.move(temp, target, StandardCopyOption.ATOMIC_MOVE, StandardCopyOption.REPLACE_EXISTING);
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        }
    }
}
```

The `issue` UDA comes from `TestTaskwarrior`'s taskrc (Task 5), mirroring the real setup. The `note` UDA is intentionally **not** there; `TaskStore` creates it on the first write.

Design notes:
- Æsh instantiates command classes itself, so commands reach their dependencies through `Context.current()`, a holder set by `Ztk.run` for the duration of one invocation. Config and the store load lazily, so `help`, `--help` and `completion` work without a config file.
- Output rule (spec §6.1): JSON when `--json` is passed or stdout is not a TTY; `--human` forces human output. Path-result commands print only the path (or `{schema,id,path}` with `--json`), with human messages on stderr.
- Exit codes: commands never return non-zero `CommandResult`s; they throw `ZtkException`. So any non-zero Æsh result is an Æsh usage error, which maps to 1.
- `--json`/`--human` are global flags, stripped by `Ztk.run` before Æsh sees the arguments (wherever they appear, except after a literal `--`). `--config <path>` is only accepted as the first argument.

```java
import java.io.PrintStream;
import java.nio.charset.StandardCharsets;
import java.util.Map;

/**
 * Runs ztk in-process with captured stdout/stderr.
 */
public final class CliHarness {

    public record Result(int exit, String out, String err) {
    }

    private CliHarness() {
    }

    public static Result run(Map<String, String> env, boolean tty, String... args) {
        PrintStream originalOut = System.out;
        PrintStream originalErr = System.err;
        ByteArrayOutputStream out = new ByteArrayOutputStream();
        ByteArrayOutputStream err = new ByteArrayOutputStream();
        try {
            System.setOut(new PrintStream(out, true, StandardCharsets.UTF_8));
            System.setErr(new PrintStream(err, true, StandardCharsets.UTF_8));
            int exit = Ztk.run(args, env, tty);
            return new Result(exit, out.toString(StandardCharsets.UTF_8), err.toString(StandardCharsets.UTF_8));
        } finally {
            System.setOut(originalOut);
            System.setErr(originalErr);
        }
    }
}
```

```java
import java.io.UncheckedIOException;
import java.nio.file.Path;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.node.ObjectNode;

import io.github.jabolina.ztk.Context;

/**
 * The only place that writes command results (spec §6.1).
 */
public final class Output {
    public static final ObjectMapper JSON = new ObjectMapper();

    private Output() {
    }

    public static ObjectNode object() {
        ObjectNode node = JSON.createObjectNode();
        node.put("schema", 1);
        return node;
    }

    /** A normal result: human text on a TTY, JSON otherwise. */
    public static void result(String human, ObjectNode json) {
        if (Context.current().json()) {
            System.out.println(write(json));
        } else {
            System.out.print(human.endsWith("\n") ? human : human + "\n");
        }
    }

    /** Path-result commands: bare path, or {schema,id,path} with --json; message to stderr. */
    public static void path(String id, Path path, String humanMessage) {
        if (humanMessage != null && !humanMessage.isEmpty()) {
            System.err.println(humanMessage);
        }
        if (Context.current().json() && jsonRequested()) {
            ObjectNode node = object();
            node.put("id", id);
            node.put("path", path.toString());
            System.out.println(write(node));
        } else {
            System.out.println(path);
        }
    }

    /** Informational message for humans; always stderr so stdout stays parseable. */
    public static void message(String text) {
        System.err.println(text);
    }

    private static boolean jsonRequested() {
        return Context.current().explicitJson();
    }

    private static String write(ObjectNode node) {
        try {
            return JSON.writeValueAsString(node);
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        }
    }
}
```

```java
            values.put(key, value);

        Output.result(human.toString(), json);
```

```java
package io.github.jabolina.ztk;

import java.io.Console;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.Optional;

import org.aesh.AeshRuntimeRunner;
import org.aesh.command.CommandResult;

import io.github.jabolina.ztk.Context.OutputMode;
import io.github.jabolina.ztk.cli.ZtkCommand;

public final class Ztk {

    private Ztk() {
    }

    public static void main(String[] args) {
        System.exit(run(args, System.getenv(), stdoutIsTerminal()));
    }

    /**
     * Output mode depends on stdout only. Console.isTerminal() requires stdin AND stdout to be
     * terminals, which would wrongly switch to JSON for `… | ztk session add --summary -` (Phase 4).
     * On Linux, /proc/self/fd/1 links to /dev/pts/N or /dev/ttyN when stdout is a terminal.
     */
    static boolean stdoutIsTerminal() {
        try {
            String target = Files.readSymbolicLink(Path.of("/proc/self/fd/1")).toString();
            return target.startsWith("/dev/pts/") || target.startsWith("/dev/tty");
        } catch (IOException | UnsupportedOperationException e) {
            Console console = System.console();
            return console != null && console.isTerminal();
        }
    }

    public static int run(String[] args, Map<String, String> env, boolean tty) {
        List<String> rest = new ArrayList<>(List.of(args));
        Optional<Path> configFlag = Optional.empty();
        if (rest.size() >= 2 && rest.getFirst().equals("--config")) {
            configFlag = Optional.of(Path.of(rest.get(1)));
            rest = new ArrayList<>(rest.subList(2, rest.size()));
        }
        OutputMode mode = OutputMode.AUTO;
        List<String> filtered = new ArrayList<>();
        boolean passthrough = false;
        for (String arg : rest) {
            if (!passthrough && arg.equals("--")) {
                passthrough = true;
            } else if (!passthrough && arg.equals("--json")) {
                mode = OutputMode.JSON;
                continue;
            } else if (!passthrough && arg.equals("--human")) {
                mode = OutputMode.HUMAN;
                continue;
            }
            filtered.add(arg);
        }

        Context.set(new Context(env, configFlag, tty, mode));
        try {
            CommandResult result = AeshRuntimeRunner.builder()
                    .command(ZtkCommand.class)
                    .args(filtered.toArray(String[]::new))
                    .execute();
            return result.getResultValue() == 0 ? 0 : ZtkException.USAGE;
        } catch (ZtkException e) {
            System.err.println("❌ " + e.getMessage());
            return e.exitCode();
        } catch (RuntimeException e) {
            Throwable cause = e;
            while (cause.getCause() != null && !(cause instanceof ZtkException)) {
                cause = cause.getCause();
            }
            if (cause instanceof ZtkException z) {
                System.err.println("❌ " + z.getMessage());
                return z.exitCode();
            }
            throw e;
        } finally {
            Context.set(null);
        }
    }
}
```

Also: `--aesh-complete` must stay `args[0]` for Æsh's built-in completion; `Ztk.run` does not reorder arguments, so `ztk --aesh-complete -- …` keeps working.

```java
    /** Taskwarrior accepts abbreviations: pro:, proj:, … project:. */
    private static final Pattern PROJECT = Pattern.compile("^pro(j(e(c(t)?)?)?)?:.+");

    @Arguments(description = "Description and Taskwarrior attributes")
    private List<String> words;

    @Override
    public CommandResult execute(CommandInvocation invocation) {

        ObjectNode json = Output.object();
        json.put("id", task.id());
        json.put("uuid", task.uuid());
        json.put("description", task.description());
        Output.result("Created task " + task.id() + ".", json);
        return CommandResult.SUCCESS;
    }
}
```

```java
import java.nio.file.Path;
```

```java
import io.github.jabolina.ztk.Context;

public final class Editor {

    private Editor() {
    }

    /** Fails before any side effect when not on a TTY; call first in editor commands. */
    public static void requireTty(String alternative) {
        if (!Context.current().tty()) {
            throw ZtkException.usage("🤖 Not a terminal: editor disabled. Use '" + alternative + "' instead.");
        }

    public static void open(Path file) {
        List<String> command = new ArrayList<>(List.of(Context.current().config().editor().split("\\s+")));
        command.add(file.toString());
        try {
            new ProcessBuilder(command).inheritIO().start().waitFor();
        } catch (IOException e) {
            throw ZtkException.usage("Cannot start editor: " + e.getMessage());
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}
```

```java
package io.github.jabolina.ztk.cli;

import java.nio.file.Path;
import java.util.List;

import io.github.jabolina.ztk.Context;
import io.github.jabolina.ztk.ZtkException;
import io.github.jabolina.ztk.taskwarrior.Task;
import io.github.jabolina.ztk.taskwarrior.TaskStore;

public final class Lifecycle {

    private Lifecycle() {
    }

    /** Starts the task under the single-active-task rule; returns its (possibly new) note. */
    public static Path start(String ref) {
        TaskStore store = Context.current().store();
        Task task = store.get(ref);
        for (Task active : store.query("+ACTIVE")) {
            if (!active.uuid().equals(task.uuid())) {
                throw ZtkException.validation("Cannot start Task " + ref + ".\n"
                        + "⚠️  Task " + active.id() + " is currently active: '" + active.description() + "'\n"
                        + "💡 Run 'ztk stop' or 'ztk done " + active.id() + "' first.");
            }
        }
        Path note = Context.current().notes().ensure(task);
        if (task.active()) {
            // Taskwarrior exits 1 ("already started") on a second start; re-running begin must
            // still succeed and print the path, as the bash script does.
            store.modify(task, List.of("+week", "-review"));
        } else {
            store.start(task, List.of("+week", "-review"));
        }
        return note;
    }
}
```

### Task 13: Bash completion with Taskwarrior fallback

**Files:**

- Create: `src/main/java/io/github/jabolina/ztk/cli/commands/CompletionCommand.java`

Mechanism (spec §7.2, adapted to Æsh's built-in `--aesh-complete`, confirmed in Task 2):
1. The bash function runs `ztk --aesh-complete -- <words up to the cursor>` and uses the candidates.
2. If there are none, the subcommand is one of `add`, `list`, `ls` or `week`, and Taskwarrior's `_task` function is available (loaded from `/usr/share/bash-completion/completions/task` on demand), it rewrites the words into the equivalent `task …` command and calls `_task`.

The program name is a placeholder, `@PROG@`, substituted at print time, so the same script serves `ztk2` during rollout and `ztk` afterwards.

- [ ] **Step 1: Write the script**

```bash
# bash completion for @PROG@ — generated by `@PROG@ completion bash`.
# Usage: source <(@PROG@ completion bash)   (e.g. in ~/.bashrc)

_@PROG@_task_fallback() {
    local sub="$1"
    if ! declare -F _task >/dev/null; then
        declare -F _completion_loader >/dev/null && _completion_loader task 2>/dev/null
        declare -F _task >/dev/null || return 1
    fi
    local -a words
    if [[ "$sub" == "add" ]]; then
        words=(task add "${COMP_WORDS[@]:2}")
        COMP_CWORD=$COMP_CWORD
    else
        words=(task "${COMP_WORDS[@]:2}")
        COMP_CWORD=$((COMP_CWORD - 1))
    fi
    COMP_WORDS=("${words[@]}")
    COMP_LINE="${words[*]}"
    COMP_POINT=${#COMP_LINE}
    _task task "${COMP_WORDS[COMP_CWORD]}" "${COMP_WORDS[COMP_CWORD-1]}"
}

_@PROG@_complete() {
    local cur="${COMP_WORDS[COMP_CWORD]}"
    local sub="${COMP_WORDS[1]}"
    local IFS=$'\n'
    local candidates
    candidates=$(@PROG@ --aesh-complete -- "${COMP_WORDS[@]:1:COMP_CWORD}" 2>/dev/null \
        | grep -v '^__aesh_\(file\|dir\)__$' | cut -f1)
    if [[ -n "$candidates" ]]; then
        COMPREPLY=( $(compgen -W "$candidates" -- "$cur") )
        return 0
    fi
    COMPREPLY=()
    if (( COMP_CWORD >= 2 )); then
        case "$sub" in
            add|list|ls|week) _@PROG@_task_fallback "$sub" ;;
        esac
    fi
}

complete -o nosort -F _@PROG@_complete @PROG@
```

```java
@CommandDefinition(name = "completion", description = "Print the shell completion script", generateHelp = true)
public class CompletionCommand implements Command<CommandInvocation> {
    @Argument(description = "Shell (bash)", required = true)
    private String shell;

    @Override
    public CommandResult execute(CommandInvocation invocation) {
        if (!shell.equals("bash")) {
            throw ZtkException.usage("Only bash is supported.");
        }
        String program = Path.of(ProcessHandle.current().info().command().orElse("ztk")).getFileName().toString();
        if (program.equals("java")) {

        } catch (IOException e) {
            throw new UncheckedIOException(e);
        }
        return CommandResult.SUCCESS;
    }
}
```
