# ztk

Tasks and notes in your terminal, for you and your coding agents.

```sh
curl -fsSL https://raw.githubusercontent.com/jabolina/ztk/main/scripts/install.sh | sh
```

For Linux and Apple silicon Macs; needs [Taskwarrior](https://taskwarrior.org) 3.

- **Plain files.** Tasks live in Taskwarrior, notes in Markdown files you can read, grep and edit.
- **Pick up where you left off.** Each task has a note and a log of work sessions, so you or an agent can resume it in one command.
- **Goals down to tasks.** Yearly goals break into quarterly goals, quarterly goals into efforts, efforts into tasks.
- **Everything linked.** Tasks, notes and papers point to each other with `[[wikilinks]]`, and ztk tells you when a link breaks.
- **Summaries of what really happened.** Weekly, quarterly and yearly summaries are built from the work you recorded, never made up.
- **Made for agents too.** JSON output, and [skills](skills) that teach coding agents to use it.

Read the [manual](docs/manual/manual.adoc) to get started.
